# Mailings

Este directorio reúne los correos de campañas de Todo Carnes y sus recursos estáticos. Cada campaña vive en una carpeta numerada e independiente para mantener estables las rutas relativas de imágenes, tipografías y otros elementos.

## Estructura

```text
mailings/
└── 01_food-service/
    ├── index.html
    └── assets/
```

Para crear una nueva campaña, agrega una carpeta correlativa (`02_nombre-campaña`, `03_nombre-campaña`, etc.) y conserva todos sus recursos dentro de su propio directorio.
