# Mockups de maquila

Reemplaza estos tres archivos para actualizar la diapositiva de maquila sin tocar código:

- `bolsa-vacio.webp`
- `bandeja-sellada.webp`
- `caja-personalizada.webp`

Usa imágenes WebP horizontales, idealmente de 960 x 640 px o más. Cada mockup debe dejar una zona
frontal despejada y centrada: el generador superpone allí el logo del cliente cargado en el catálogo.

Conserva exactamente los nombres de archivo. Si la superficie del envase cambia de posición, también
se deben ajustar en `components/templates/CatalogPackaging.tsx` el ancho y la posición de la capa del
logo.
